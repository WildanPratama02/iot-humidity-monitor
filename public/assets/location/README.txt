This folder structure should contain subfolders for each location:

/assets/location/
├── AQL F1&2/
│   ├── QR Action.png
│   ├── QR Summary.png
│   └── SOP.jpg
├── IMWH B1/
│   ├── QR Action.png
│   ├── QR Summary.png
│   └── SOP.jpg
├── IMWH B2/
│   ├── QR Action.png
│   ├── QR Summary.png
│   └── SOP.jpg
└── ... (other locations)

Each location folder should contain:
1. QR Action.png - QR Code for Action Plan (Google Form)
2. QR Summary.png - QR Code for Summary Action Plan (Google Sheets)
3. SOP.jpg - Standard Operating Procedure document image

The folder name must exactly match the location name as defined in lib/locationData.ts
